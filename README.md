# Marque AI Business Assistant

A React and TanStack Start workspace for business communication and productivity assistance.

## Features

- **Business requests** with optional additional context, task type, and tone selection.
- **Document and image attachments**: PDF, DOCX, XLSX, TXT, PNG, JPG/JPEG. Up to **5 files**, **20 MB each**, **30 MB total**.
- **Multimodal analysis**: images and PDFs are sent to Gemini as inline data; DOCX/XLSX text is extracted server-side; TXT is read directly.
- **Light and dark theme** toggle with system preference detection.
- Attachment content is treated as untrusted reference data and cannot override the system instructions.

## Architecture

- **UI** (`src/components/business-assistant/`): focused, reusable components for the request form, attachment uploader, and response panel. Shared primitives live in `src/components/ui/`.
- **Assist providers** (`src/lib/assist/`): the `AssistProvider` interface is implemented by `ApiAssistProvider` (calls the server) and `MockAssistProvider` (tests and offline use). Attachment formats, limits, and validation live here so they can be reused by client and server.
- **Server** (`src/server/`): `POST /api/assist` validates the request (including attachments) and calls the Gemini service in `src/server/ai/`. Provider credentials never reach the browser.
- **Routing** (`src/routes/`): TanStack Router file-based routes; `src/routeTree.gen.ts` is generated by the framework and must not be edited by hand.

## Prerequisites

- **Node.js >= 22.12.0** (required by `@tanstack/react-start`)
- **npm** (the repository ships a `package-lock.json`)

## Environment setup

Copy the template and fill in your credentials:

```sh
cp .env.example .env
```

| Variable         | Required | Description                                             |
| ---------------- | -------- | ------------------------------------------------------- |
| `GEMINI_API_KEY` | yes      | Google Gemini API key from https://aistudio.google.com/ |
| `GEMINI_MODEL`   | no       | Overrides the default Gemini model used by the service. |

Secrets live only in environment variables and are never exposed to browser code. `.env` is git-ignored; `.env.example` is the safe, key-less template.

| `npm run build`      | Production build.                 |

| `npm run lint`       | Run ESLint.                       |
| `npm run typecheck`  | Type-check with `tsc --noEmit`.   |
| `npm run format`     | Format with Prettier.             |
| `npm test`           | Run the test suite once (Vitest). |
| `npm run test:watch` | Run tests in watch mode.          |
